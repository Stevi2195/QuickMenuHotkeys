[size=4][b]Quick Menu Hotkeys[/b][/size]

[line]

Tired of holding ESC, navigating the radial wheel, and releasing just to open a menu?

This mod adds direct keyboard and controller shortcuts for opening Crimson Desert menus instantly with a single button press. No radial wheel needed.

[line]

[size=3][b]Default Hotkeys[/b][/size]

[list]
[*][b]I[/b] = Inventory
[*][b]J[/b] = Quest Book / Journal
[*][b]K[/b] = Skill Tree
[*][b]L[/b] = Knowledge
[*][b]O[/b] = Options / Others
[*][b]M[/b] = World Map
[/list]

[size=3][b]Features[/b][/size]

[list]
[*][b]Direct menu switching:[/b] Open one menu and jump straight to another without closing and reopening the radial menu.
[*][b]Fully configurable:[/b] All hotkeys can be changed or disabled through the INI file. Set any key to [b]00[/b] to disable it.
[*][b]Extra panels:[/b] Additional game menus such as Challenges, Faction Quests, Guides, and Notifications can be assigned manually.
[*][b]Update-proof:[/b] Uses automatic pattern scanning to locate internal game functions instead of relying on hardcoded offsets.
[*][b]Works immediately:[/b] Hotkeys are available as soon as gameplay starts. The mod resolves the game's PanelManager automatically.
[*][b]Direct internal calls:[/b] Opens panels by calling the game's internal panel functions directly instead of simulating menu navigation.
[*][b]Override game keys:[/b] When you remap a hotkey (e.g. Inventory from I to Tab), the game's hardcoded keybind for that key is automatically disabled — freeing it for other in-game actions like abilities.
[*][b]Xbox / XInput controller:[/b] Assign controller buttons to any panel via XInput. Supports an optional modifier button (e.g. hold LB + press D-Pad). Works with Xbox controllers natively and all other controllers through Steam Input.
[*][b]PS5 / PS4 controller:[/b] Native HID support for DualSense and DualShock 4 — no Steam Input required. Configurable PSButton per panel and optional PSModifier (e.g. hold L1 + press Cross). D-Pad buttons supported (DPadUp, DPadDown, DPadLeft, DPadRight).
[*][b]No double-trigger on modifier combos:[/b] When a controller modifier is held (e.g. LB / L1), the bound panel button is masked from the game so the same press doesn't also fire the default action (consume item, etc.). The modifier itself stays active.
[*][b]Keyboard modifiers:[/b] Bind multiple panels to the same key with different modifiers (e.g. Shift+J for Faction Quests, Ctrl+J for Challenges).
[*][b]Crash protection:[/b] If a game update breaks the hook, the mod disables itself instead of crashing the game.
[/list]

[size=3][b]Antivirus Notice[/b][/size]

Some antivirus programs may flag this mod because it relies on low-level hooking to access the game's internal menu functions directly.

Crimson Desert does not provide an official mod API for this functionality, so the mod has to locate and call internal game functions in memory. That kind of behavior can look suspicious to antivirus software even when the mod itself is not malicious.

Because of that, these flags may not fully disappear without breaking the way the mod works.

[size=3][b]Configuration[/b][/size]

Edit [b]QuickMenuHotkeys.ini[/b] to customize hotkeys:

[code][Settings]
Enabled=1           ; Master switch (0=off, 1=on)
DebugLog=0          ; Create log file for troubleshooting (0=off, 1=on)
OverrideGameKeys=1  ; Block game's hardcoded keybinds when remapped (0=off, 1=on)
ControllerEnabled=1 ; Controller support (0=off, 1=on)
ControllerModifier=0000 ; Hold this button before panel buttons (0000=none, 0100=LB)

; --- Core panels (default keybinds) ---
[Inventory]
Hotkey=49           ; I

[QuestBook]
Hotkey=4A           ; J

[SkillBook]
Hotkey=4B           ; K

[Knowledge]
Hotkey=4C           ; L

[Options]
Hotkey=4F           ; O

[Map]
Hotkey=4D           ; M

; --- Extra panels (assign your own keys) ---
[Challenge]
Hotkey=00           ; disabled by default

[FactionQuest]
Hotkey=00           ; disabled by default

[Guides]
Hotkey=00           ; disabled by default

[Notifications]
Hotkey=00           ; disabled by default

[Pet]
Hotkey=00           ; disabled by default[/code]

Key codes use Windows Virtual Key Codes in hex format. A full reference table covering letters, numbers, F1–F24, numpad, navigation, modifiers, punctuation, mouse buttons, and media keys is included at the bottom of the INI file.

[size=3][b]Controller Setup[/b][/size]

To assign controller buttons, add [b]ControllerButton[/b] to any panel section. Use [b]ControllerModifier[/b] to require holding a button (recommended to avoid conflicts with in-game controls):

[code][Settings]
ControllerEnabled=1
ControllerModifier=0100  ; Hold LB before pressing panel buttons

[Inventory]
Hotkey=49
ControllerButton=0001    ; D-Pad Up

[QuestBook]
Hotkey=4A
ControllerButton=0008    ; D-Pad Right

[Map]
Hotkey=4D
ControllerButton=0002    ; D-Pad Down[/code]

In this example, [b]LB + D-Pad Up[/b] opens Inventory, [b]LB + D-Pad Right[/b] opens the Quest Book, etc.

[b]Controller button values:[/b] DPAD_UP=0001, DPAD_DOWN=0002, DPAD_LEFT=0004, DPAD_RIGHT=0008, START/MENU=0010, BACK/VIEW=0020, LEFT_STICK=0040, RIGHT_STICK=0080, LB=0100, RB=0200, A=1000, B=2000, X=4000, Y=8000

[b]Non-Xbox controllers via Steam Input:[/b] Switch and other non-Sony controllers are supported through Steam Input, which translates them to XInput automatically.

[size=3][b]PS5 / PS4 Controller Setup[/b][/size]

PS5 DualSense and PS4 DualShock 4 controllers are supported natively via HID Raw Input — no Steam Input required. Add [b]PSButton[/b] to any panel section and optionally set a [b]PSModifier[/b]:

[code][Settings]
PSModifier=L1            ; Hold L1 before pressing panel buttons

[Inventory]
PSButton=Cross           ; L1 + Cross opens Inventory

[QuestBook]
PSButton=Square          ; L1 + Square opens Quest Book

[Map]
PSButton=Triangle        ; L1 + Triangle opens Map[/code]

[b]Supported PSButton values:[/b] Circle, Triangle, Square, Cross, L1, R1, L3, R3, Share, Options, Touchpad, PS, Mute, DPadUp, DPadDown, DPadLeft, DPadRight (case-insensitive, "none" to disable)

Supports DualSense, DualSense Edge, and DualShock 4 v1/v2.
