Quick Menu Hotkeys v1.11.0
for Crimson Desert (game version 2.02.00)

==================================================================
INSTALLATION
==================================================================
1. Make sure Ultimate ASI Loader (version.dll) is installed in:
      [Steam]\steamapps\common\Crimson Desert\bin64\
2. Copy these two files into that same bin64 folder:
      QuickMenuHotkeys.asi
      QuickMenuHotkeys.ini
3. Launch the game. The mod activates automatically once in-game.

Default hotkeys: I = Inventory, J = Journal, K = Skills,
L = Knowledge, O = Options, M = World Map. All keys and controller
buttons are configurable in QuickMenuHotkeys.ini.

==================================================================
UNINSTALL
==================================================================
Delete QuickMenuHotkeys.asi and QuickMenuHotkeys.ini from bin64.

==================================================================
SOURCE CODE / ANTIVIRUS NOTE
==================================================================
This mod is open source. The full source code is public so anyone
can review or compile it themselves:
      https://github.com/  (see the mod's Nexus page for the link)

Like most game mods, Quick Menu Hotkeys works by attaching to the
running game to read key presses and open menus. Some antivirus
programs use heuristics that flag this behaviour on unsigned mod
DLLs as a precaution, even though the mod is harmless. If your
scanner reports it, that is a false positive. When in doubt,
compile the mod yourself from the public source.
